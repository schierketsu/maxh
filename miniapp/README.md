# Мера — мини-приложение MAX

AI-агент господдержки бизнеса: онбординг по ИНН → профиль → подходящие меры поддержки.

Профиль компании по ИНН приходит с HTTP API бота (`bot/`, см. его README) —
он ходит в DaData. Перед запуском поднимите бот (`cd bot && npm start`), он
слушает `http://localhost:3001`, а Vite-дев-сервер проксирует `/api/*` туда же.

## Запуск

```bash
cd miniapp
npm install
npm run dev
```

Откройте http://localhost:5173

## ИНН для проверки

Подойдёт любой реальный ИНН (10 или 12 цифр) — данные подтягиваются из DaData.
