# Мера — мини-приложение MAX

Два режима за одним выбором на главном экране:

- **Господдержка** — онбординг по ИНН → профиль → подходящие меры поддержки.
- **B2B-сеть** — онбординг по ИНН → лента заявок от других компаний,
  свободный текст «мне что-то нужно» → AI (Claude) превращает его в
  структурированную заявку → уведомление в MAX подходящим по ОКВЭД
  компаниям → они оставляют предложение.

Профиль компании по ИНН приходит с HTTP API бота (`bot/`, см. его README) —
он ходит в DaData. Перед запуском поднимите бот (`cd bot && npm start`), он
слушает `http://localhost:3001`, а Vite-дев-сервер проксирует `/api/*` туда же.

## Запуск

```bash
cd miniapp
npm install
npm run dev
```

Откройте http://localhost:5173

## ИНН для проверки

Подойдёт любой реальный ИНН (10 или 12 цифр) — данные подтягиваются из DaData.
